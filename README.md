#### Ответы на вопросы:
1. **Чем Console.Write() отличается от Console.WriteLine()?**

*Console.Write() не переходит на другую строку, а Console.WriteLine() переходит, из-за чего первое удобно использовать при вводе данных с клавиатуры, чтобы текст подсказки был на одной строке вместе с вводимыми данными.*

2. **Что произойдёт, если попытаться присвоить переменной типа int значение 3.14?**

*Вылезет ошибка. Ее видно еще на этапе компиляции. Будут подсказки о том, что явное преобразование в Int не дает преобразовать переменную в double. Проблема сохраняется и с int?. В runtime выдает ошибку.*

3. **. Почему 10 / 3 в C# даёт 3, а не 3.333...? Как получить дробный результат?**

*10 и 3 в этом случае оба имеют тип int, а значит и на выходе мы получим тип Int, то есть без точки. Для получения дробного результата нужно, чтобы хотя бы одно число было в дробном типе данных (double, float)*

4. **Что означает var в C#? Чем он отличается от динамической типизации в Python?**

*Var означает, что сам компилятор определяет тип в момент присваивания переменной значения. Это не похоже на динамическую типизацию в Python, потому что определенный компилятором тип закрепляется за этой переменной, а не меняется в зависимости от того, где его используют. То есть, если переменной с Var присвоили значение 4, то за ней закрепится Int, и далее по выполнении программы его нельзя изменить, а в Python можно в любой момент выполнения программы. (один из плюсов отсутствия динамической типизации то, что ошибки будут видны на этапе компиляции, а не при запуске. В Python ошибку, связанную с типами, обычно можно обнаружить только в рантайме.)*
